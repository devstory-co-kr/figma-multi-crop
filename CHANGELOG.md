# [Change Log](http://keepachangelog.com/)

All notable changes to the "Multi Crop" plugin will be documented in this file.

## [1.1.0] - 26.11.18
### Added
- `Uncrop` button that removes any existing crop and shows the whole image, keeping it in place.

### Changed
- Remove the `Crop` button. Crops are applied as you type and kept when you close the plugin or change the selection; use `Reset` or `Ctrl/Cmd + Z` to undo.

### Fixed
- Keep dragging a side label even when the pointer leaves the plugin window.

## [1.0.0] - 26.11.18
### Added
- Crop multiple selected images at once by top, right, bottom and left.
- Preview the crop live while typing, then `Crop` to keep it or `Reset` to discard it.
- Change values by dragging the side labels, like Figma's number fields.
