# [Change Log](http://keepachangelog.com/)

All notable changes to the "Multi Crop" plugin will be documented in this file.

## [1.0.0] - 26.11.18
### Added
- Crop multiple selected images at once by top, right, bottom and left.
- Preview the crop live while typing, then `Crop` to keep it or `Reset` to discard it.
- Change values by dragging the side labels, like Figma's number fields.
